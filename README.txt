Baccarat Banker Manual 20% Loss Alert

This is a separate practice app: always bet Banker using Labouchere 2,2,2,2,2, unit €0.20 by default. The app prompts once when betting losses reach about 20% of the opening bankroll for that Labouchere sequence. No automatic stop: choose Continue or Stop Game & Reset Sequence. Manual stop preserves losses, adds an entry to History, and begins a new sequence with the remaining bankroll.

To install on iPhone: host the extracted files on GitHub Pages (index.html at repository root), open in Safari and select Share > Add to Home Screen. Do not replace your main tracker unless you want this version instead.

Data is stored locally on each device and is separate from your older practice apps. Export Backup All Data regularly.
